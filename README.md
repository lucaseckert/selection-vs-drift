# Selection and drift in phenotypic change during bottlenecks

Code to reproduce simulations and figures of Eckert et al. (*accepted*) in *Can J Zool*

-   `scripts/conceptual-fig.R`: reproduces background graphics for Figure 1
-   `scripts/rouge-fig.R`: reproduces Figure 2
-   `scripts/simulations.R`: reproduces simulations presented in Figure 3
-   `tidy-data`: contains phenotypic data presented in Figure 2
